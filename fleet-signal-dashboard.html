Link the shared data folder

Point Fleet Signal at the shared network folder so it re-reads the latest device exports on its own — no more manual uploads. The folder link and its permission are stored only in this browser.

How to link it

1. Click "Choose folder" below.
2. In the picker, paste or navigate to the path above.
3. Select the folder and confirm — the browser remembers this choice for next time.

Needs Chrome or Edge. On Safari or Firefox, keep using the manual upload or drag-and-drop instead.
